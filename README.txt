JJ TRAVELS CHENNAI — STATIC WEBSITE
===================================

Files:
- index.html
- css/style.css
- js/script.js

HOW TO RUN
1. Extract the ZIP.
2. Keep the folder structure unchanged.
3. Open index.html in Chrome, or use VS Code Live Server.

IMPORTANT
- This is a static HTML/CSS/JS recreation based on the publicly readable homepage content.
- The original WordPress media library/logo was not downloadable as a complete asset pack during this build. The page uses replacement travel photos from Unsplash and a text-based JJ logo. Replace these with the original assets for a closer pixel match.
- Contact numbers, email and address are included from the live website.
- The enquiry form opens WhatsApp with the entered details; it does not store submissions on a server.
- Photos are loaded from Unsplash over the internet.
